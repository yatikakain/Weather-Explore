# Enhanced Weather App

This is an enhanced version of the original Weather App, forked from the SWOC (Social Winter of Code) event repository. Built with React.js, this application provides detailed weather information with an improved user interface and additional features.

## 🌟 New Features

- **Dynamic Layout Changes**: Responsive design that adapts to different screen sizes and orientations
- **Weather Statistics Dashboard**: Detailed weather metrics including:
  - Wind Speed
  - Humidity Levels
  - "Feels Like" Temperature
  - Atmospheric Pressure
- **Hourly Forecast**: 8-hour weather prediction with:
  - Temperature Trends
  - Weather Conditions
  - Time-based Icons (Day/Night)
- **Enhanced UI Elements**:
  - Glassmorphism Design
  - Animated Weather Icons
  - Smooth Transitions
  - Dynamic Background Effects
- **Unit Conversion**: Toggle between Celsius and Fahrenheit

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/Raghavendra-Reddy-Padala/Weather-Explore.git
```

2. Navigate to project directory:
```bash
cd weather-app
```

3. Install dependencies:
```bash
npm install
```

4. Create a `.env` file in the root directory and add your OpenWeatherMap API key:
```
REACT_APP_WEATHER_API_KEY=your_api_key_here
```

5. Start the development server:
```bash
npm start
```

6. Open `http://localhost:3000` in your browser

## 🌐 API Configuration

This app uses the OpenWeatherMap API. To use the app:
1. Sign up at [OpenWeatherMap](https://openweathermap.org/api)
2. Generate an API key
3. Add the key to your `.env` file
